# 工作台设计与状态

主任务是验证 SDK 客户端的实时输入、事件和响应。采用 MANAS 实时工作台：连续会话正文占主区域，连接配置在上方，事件检查作为可折叠的辅助区域。宽屏并排参考事件；窄屏将事件放在会话下方，保持连接状态、录音和提交可达。

视觉使用苍渊·白垣 Token 真源；默认白垣，提供苍渊切换。自然语言使用正文，model、端点和事件使用等宽排版。没有独立服务端页面或共享组件修改。

| 控件 | 角色 | 宽度与状态 |
| --- | --- | --- |
| model slug | 已发布资源标识 | 中等宽度、可输入，连接后锁定 |
| 交互模式 | 有限选择 | 转写 / 语音 Agent，连接后锁定 |
| 采样率 | 短参数 | 16 / 24 kHz，紧凑，连接后锁定 |
| 自定义下拉 | 模型候选及有限选择 | 40px 控件、主题浮层；模型可搜索或手动输入，方向键定位、Enter 选择、Escape 关闭、Tab 离开；空候选给出说明，连接后禁用 |
| 文本消息 | 长内容 | 占据会话正文宽度，只在 Agent 模式可提交 |
| 连接 / 断开 | 会话动作 | 高对比主按钮，连接中可断开 |
| 录音 / 停止 | 输入动作 | 转写使用服务端 VAD 并在停止时收尾；Agent 手动提交，先获得权限和真实采集后显示录音 |
| 审批 / 问题回答 | 请求动作 | 仅在真实事件到达时出现，用户明确操作后发送 |

| 状态 | 来源 | 操作与恢复 |
| --- | --- | --- |
| 正在检查上游 | 页面打开或刷新模型列表，请求 `/api/models` | 服务地址旁显示检查中，禁止重复读取 |
| 上游访问成功 | 上游 `/v1/models` 返回有效列表 | 显示模型数量；空列表说明需要先发布模型；会话需另外连接 |
| 上游访问失败 | 模型列表请求失败 | 显示原因并提供「重试访问」，清除过期模型候选 |
| 未连接 | 初始或用户主动断开 | 配置并连接；无结果时显示使用步骤 |
| 连接中 | 浏览器连接 + SDK 握手 | 可断开，禁止音频和文本发送 |
| 已连接 | SDK 等待 session.updated 完成 | 开始录音，Agent 可发文本 |
| 请求麦克风 | getUserMedia 未完成 | 禁止重复开启；失败保留连接，可重试 |
| 录音中 | AudioWorklet 已启动 | 转写持续使用上游 VAD，停止录音时收尾；Agent 停止并提交，或丢弃输入 |
| 临时转写 / 正式转写 | 上游 interim、delta、completed 事件 | 录音期间即时展示；interim_cleared 移除被替换的临时文本；是否返回临时结果由工作流决定 |
| 响应中 | response.created | 可取消响应；实际 response.done 后显示终态 |
| 局部错误 | 麦克风、播放器、服务端 error | 保留连接和正文，提供重试路径 |
| 连接失败 / 中断 | SDK 或桥接传输异常 | 释放媒体资源，重新配置并连接；不宣称结果排空 |

新连接清除旧连接错误、审批和计数；已有正文保留到清空操作。录音停止与连接关闭不等于服务端已排空。事件最多保留 200 条，正文最多 200 项，播放积压超过 10 秒时明确停止播放，发送积压超过 1 MiB 时停止采集并提示恢复。状态以文字补充颜色，频繁音频事件不进行 live 播报。键盘操作、可见焦点、真实控件标签、reduced-motion 与两主题对比度均纳入验证。
